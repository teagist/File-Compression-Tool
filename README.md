# S.Q.U.E.E.Z.E.

## Streamlined Quality Utility for Efficient Encoding and Zipping Engine
This project is a file compression tool that makes use of Huffman's algorithm for encoding text.  There is a command line interface and a desktop application that will allow you to select a file to compress.

The current goal is to make the comman line interface into a program with command line arguments.  Currently in the testing phase and once changes are complete, the arguments will be integrated.

For the desktop application, will need to verify that after compression the file can be returned to its original form without data loss.
